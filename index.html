Automation Reliability Investigation

Stabilizing ERPNext Autocomplete Automation

During ERPNext QA automation development, tests that selected an item from the Frappe autocomplete became unreliable under CI load. This case study documents the investigation, as recorded in the project's root-cause analysis.

Failure Observation

Tests that selected an item from the autocomplete timed out waiting for the dropdown options to become visible, especially under CI load. Playwright reported the option elements as present in the DOM but hidden.

Reproduce

Read the Playwright failure output. The option element was found repeatedly but resolved as hidden, even though the correct text had been entered in the field.

Observe

Inspected the page state. The option elements were in the DOM and aria-selected was set correctly, but they stayed hidden by CSS. Frappe's autocomplete (Awesomplete) reveals its dropdown in response to keyboard input events.

Investigate

Compared interaction methods. fill() sets the value directly and does not fire the key events the autocomplete listens for. Separately, a silent .catch() fallback pressed Enter whenever the visibility wait failed, so some tests passed without proving the intended selection happened.

Root Cause

The test's interaction did not match how the Frappe autocomplete works. fill() bypassed its keyboard handling, and the silent error suppression hid the resulting failures behind false passes.

Fix

In the item-selection step, typed the search text with type() and a delay, waited for the listbox to be attached to the DOM rather than visible, selected the option with ArrowDown and Enter, and removed the silent error suppression.

Verify

Re-ran the suite locally and in GitHub Actions after the change. The repository's execution report records the passing local and CI runs.

Lesson

A passing test only counts if it exercises the intended path. Interact with the application the way users do, wait for the state the application actually exposes, and never let error handling turn a failure into a pass.
