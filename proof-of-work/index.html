Counting method

116 counts unique test definitions, counted from each repository’s test files at the commit shown here and cited on its project page (the same list playwright test --list prints): Automation Exercise 26 (789d413), ERPNext 6 (8990014), RESTful Booker 47 (a385240), Razorpay 37 (da9e7a2). It is not a coverage measure, not a count of executions and says nothing about whether those tests pass. ERPNext’s 6 includes 1 authentication setup test, and 3 of Razorpay’s 37 are live-mode tests run separately (34 run in CI). CI results are historical. The last runs were 29 August (Automation Exercise), 14 September (Razorpay) and 22 October 2026 (RESTful Booker, whose latest commit only added a manual workflow trigger), and all three passed. ERPNext’s last green run was 4 September; its latest run, on 22 October 2026, failed because the hosted test instance it needs is gone (by my reading of the job log). I checked all four run lists on 22 October 2026. CI is configured with retries.
