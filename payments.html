Critical Scenarios I Cover

  • 3DS2 "Challenge" Paths: Verifying that the UI handles SMS and App authentication pop-ups without losing the session state.
  • Webhook Reliability: I test if the system correctly updates the database when a payment is successful but the user closes their browser before reaching the 'Thank You' page.
  • Declined Card Logic: Differentiating between 'Insufficient Funds' (soft decline) and 'Stolen Card' (hard decline) to trigger the right user messaging.
  • Negative Testing: Using "Magic Values" to force timeout errors and verifying the system gracefully rolls back the transaction.
